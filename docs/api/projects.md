# Projects

| Method | Route              | Description                          |
| ------ | ------------------ | ------------------------------------- |
| GET    | `/projects`        | List your projects                    |
| POST   | `/projects`        | Create a project (`{ name }`)         |
| GET    | `/projects/{id}`   | Get a project, with its tables        |
| DELETE | `/projects/{id}`   | Delete a project                      |
